# To-Do List

A simple, responsive to-do list built with HTML, CSS, JavaScript, and Bootstrap 5.

## Features

- Add, complete, and delete tasks
- Filter by all, active, or completed tasks
- Clear all completed tasks
- Automatically saves tasks in `localStorage`
- Responsive Bootstrap layout
- Keyboard-friendly controls
- Edit existing tasks

## Run locally

Open `index.html` in a browser, or start a local server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Project structure

- `index.html` — page structure and Bootstrap markup
- `style.css` — custom responsive styling
- `script.js` — task management and local storage logic
